PA1/PA6 are internally bonded on pin17: leave PA6 high impedance. Use HSI,
not an external crystal on PA1/PA2. GPIO_FullRemap_TIM1 selects remap9;
GPIO_PartialRemap1_USART2 selects remap1. Keep all complementary outputs off;
they are not additional independent PWM lanes and collide with other functions.
Eight independent duty settings share two timer timebases, not eight frequencies.
Dedicated reset is PC5 on this package; do not carry over V003 PD7 option-byte
provisioning. The two unused button pins alone did not solve TSSOP20's pin budget.

Electrical changes from v3.1
The inherited 3.3V LED/HC138/PMOS/NMOS/33R architecture and pulse/current
limits remain. No new peak-current qualification is claimed. R49 is fitted;
PD7 is an ordinary row pin on the selected package. PC4 drives HC138 pin4;
R72=47k pulls it high, disabling all columns at reset. HC138 pin5 remains
GND; pin6 remains VCC. Configure row outputs low, remaps/timers and decoder
addresses before driving LED_BLANK low. Hold it high through updates and errors.
Existing gate-source biases remain. Confirm startup/blank timing physically.

Vertical interface mirrors the existing horizontal one: R69/R70=1k series
on local TX/RX respectively, R71=10k receive idle pull-up. A seam therefore
has two1k resistors; this is an unqualified damping/protection candidate.
R73=10k and C6=100n form local reset bias/filter; verify WCH reset timing and
recovery access physically. TP1/2/3 expose reset/clock/spare, alongside J2 SWIO.
R11/R12 are fitted on exactly one tile in the entire connected I2C array.
All supplies/grounds share one rail. Hot-plug and mixed power are unqualified.

Geometry and contacts
49.6mm square, 6.2mm pixel pitch, first/last centres3.1/46.5mm on each axis.
Uniform pitch holds within a tile and across an abutted seam. Four2.2mm M2
NPTH holes at (6.2,6.2), (43.4,6.2), (6.2,43.4), (43.4,43.4). Native front
courtyards pass with a small nominal LED/mount margin; real screw, washer,
diffuser and housing tolerances require review. Existing diffuser/carrier
files are not compatible with this changed geometry and were not rewritten.

J1 east x48.33, J3 west x1.27; pads increase north-to-south.
J4 north y1.27, J5 south y48.33; pads increase west-to-east.
Each has seven positions at6.2mm pitch, coordinates6.2..43.4mm.
Pads1/2 VCC,3 SDA,4 SCL,5 directed data,6/7 GND. Pad5 is eastTX/westRX,
northTX/southRX. Matching pad numbers align across each seam. The inherited
native layer-specific0.8mm PTH padstacks remain; nominal wire bridge span2.54mm.
Every tile stays upright; rotating a tile breaks the pin convention. These
are soldered wire contacts, not an approved castellated fabrication process.

Topology and firmware port contract
Host/head at southwest (x0,y0); coordinates increase east and north. Forward
north only along the first column, then east along each row. This deterministic
spanning tree reaches every tile in a complete W-by-H rectangle without duplicate
broadcasts. Other vertical links are available for explicitly routed traffic;
do not forward blindly in both directions. Missing tiles/holes need a separate
routing policy and are outside this first rectangular-array study.

Packets need version, type, source/destination or rectangle, sequence/epoch,
bounded length and CRC. Derive coordinates by hop counts and verify stable
identity/coordinates with I2C status. Stage frame data in inactive RAM buffers,
poll per-tile readiness, then commit at a future shared frame epoch. Arrival
order is not synchronization. I2C aggregate ACK is not proof that every tile
is ready. UART2 is the second axis, not a reverse link on the first axis.

Port with the V006 SDK/startup/linker, 62KiB flash/8KiB RAM and the table above.
Review interrupt vector/ABI, flash offsets, USART2 interrupts, timer remaps,
refresh/pulse bounds and loader handoff; do not merely rename the V003 target.
Preserve the existing v3 application and separately implement the new target.
A new application binary and network loader have NOT been built or flashed.

Scaling limits
A rectangular topology does not imply unlimited tile count. Shared I2C7-bit
address space, capacitance, rail/seam current and timing bound each array.
Begin I2C at100kHz with exactly one intended pull-up pair. At4.7k and400pF,
tr=0.8473*Rp*Cb is about1.59us, exceeding standard-mode1us;4.7k supports
about251pF for that rise-time bound. A2.2k pair gives about0.75us at400pF,
but choose from measured capacitance/rise time and target sink ratings.
Do not silently fit extra parallel pull-ups. Bus clear/timeouts are required;
a physically stuck SCL can require local reset/power-cycle. Provide deliberate
power injection and measure drops/current at the maximum planned rectangle.
