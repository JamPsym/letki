1. EXACT IMPORT / EXPORT GATE
project/roundtrip.mjs attempts the accepted native PCB without edits.
Initial attempt exposed the missing exporter dependency. After installing it,
the importer failed: Class "padstack" not registered via SxClass.register.
No no-edit roundtrip board was produced. See logs/roundtrip-v2.log.
This concerns the installed versions and this board; it is not a universal
claim about all KiCad files or future releases.

2. NATIVE TSCIRCUIT RECONSTRUCTION
extract_reference.py reads the isolated native board into reference-fixture.json.
project/index.circuit.tsx builds custom pad footprints and traces from it.
All146 placements were held fixed; this did not test automatic placement.
No new circuit/parts selection was performed. Generic chip elements carry
physical pin/net data; semiconductor/power semantics remain underspecified.
The reconstruction deliberately does not preserve authored copper/planes,
silkscreen, model/courtyard/library identity or complete project metadata.
It uses four layers,0.2mm trace/clearance requests,0.6/0.3mm ordinary vias,
no blind/buried vias and no requested via-in-pad. GND traces request0.5mm,
VCC1mm and selected-column nets0.5mm. These are diagnostic routing inputs,
not a replacement for v3.1's reviewed2mm distribution and plane contracts.
Front/inner circular edge-contact lands are used on all layers in this
reconstruction;14reviewed rear oval lands are therefore explicitly lost.
Original schematic/project/rules were restored beside exports before grading.
No check/severity/exclusion was relaxed.

REFERENCE / INTERPRETATION
Fresh reference DRC/parity/open/excluded findings:0. Reference contains
974segments,131vias and2077.388mm of tracks, plus its authored planes.
The reconstructed candidate has no zones and different power treatment.
Length/via differences are descriptive, not a like-for-like quality ranking.
Input/after source hashes are retained; the complete source comparison must
remain unchanged. Initial helper mistakes (a temporary SWIG bounding-box
reference and duplicate-number pad comparison) were corrected before the
reported audits; raw intermediate audit reports are retained separately.
The duplicate-via diagnostic emitted native API/deallocation warnings; saved
native reports, not successful process exit alone, determine its outcome.

Useful conclusion: tscircuit is operational locally and useful for concise
repeated circuit experiments. Existing v3.1 migration is blocked at exact
import, and this simplified full-board routing run still has real faults.
Keep it as experiment evidence, not a successor revision or a tool ranking.
