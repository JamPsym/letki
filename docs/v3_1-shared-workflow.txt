HANDOFF BETWEEN EDITORS AND AGENT
1. Save human edits before an agent edit handoff; agent first checks the open
   file identity, unsaved state/capabilities and latest disk content.
2. For an open PCB, prefer native IPC edits in one labelled undo transaction,
   then save. Use live schematic IPC only if the installed version supports
   the required operations. Never assume an API advertised by bindings exists.
3. If an edit requires an external source-file rewrite, first save and close
   that editor, edit the canonical files with before/after checks, then reopen.
   Refresh redraws the canvas; it does not reliably reload externally edited files.
4. Human schematic edits reach PCB via Tools > Update PCB from Schematic (F8)
   in this same project. Review the proposed update; synchronization is followed
   by copper/zone/DRC/parity and project-specific checks.
5. Record unfinished work explicitly. One edit location does not mean every
   intermediate state is checked, physically qualified or ready for fabrication.
