Milestone ID: v3-general-r3-20261017

Status: verified functional baseline on the existing five-board v3 chain.

WHAT THIS ESTABLISHES

New text, bitmap assets, brightness envelopes and arbitrary PC-generated effects
can be delivered over UART without another application flash. Boards retain
bounded rendering, independent PWM/scan refresh, validated content storage and
timestamped frame queues. The shared I2C bus distributes the show clock.

Supported paths: loaded RAM playback; persistent safe A/B or maximum-capacity
flash playback; timed replacement of RAM segments; real-time MONO1/GRAY4/LEVEL8
frames; synchronized PC music and narration. Each tile can receive its own program.
The driver discovers actual capacities and exposes explicit replacement policy.

MEMORY AND IDENTITIES

All roles: 2036/2048 RAM bytes including the reserved 256-byte stack.
Compiler assessment: 236/256 bytes for combined foreground/ISR stack paths.
Each tile: 752-byte shared arena; default two LEVEL8 slots leave 592 program bytes.
Persistent programs: 1472 bytes with safe A/B replacement, or 3008 bytes with
explicit capacity replacement. Application images: head 13272 bytes, others 13284.
Exact image/source hashes and position-to-UUID mapping are in the adjacent JSON.

REPEAT / USE

From the repository root:
  make general-host
  python3 scripts/letki_general.py inspect
  python3 scripts/letki_general.py text 'LETKI DZIAŁA' --mode fall
  python3 scripts/letki_general.py play

The last command starts the currently active loaded program at position zero.
A chain restart selects the newest valid persistent program. Returning from a
RAM object to a new persistent upload needs an explicit replacement transition;
see the storage-policy notes in firmware/general/README.txt.

With the prepared score and the documented audio Python environment:
  .tools/native-tts/bin/python scripts/letki_general.py --baud 230400 stream config/general/pwm-show.json --fps 18 --audio build/pwm-show/audio/score.wav
  python3 scripts/letki_general.py play
Streaming retains active flash programs when every tile has one. The second
command returns to that retained program. See firmware/general/README.txt for
RAM replacement behavior, other modes, dependencies and controls.

LIMITS RETAINED

18 fps is the final measured streaming setting; automatic 22 fps was not
reliable in every run. 460800 failed the PC-to-head zero-error criterion;
921600 remains unqualified. Initial reconnect timeouts were observed, with
subsequent discovery trials passing. Independent receiver restart needs host
PLAY to restore a common show phase. Runtime stack high-water, supply/current,
continuous electrical waveforms and optical timing skew remain unmeasured.
This milestone establishes the v3 functional baseline, not v4 qualification.
